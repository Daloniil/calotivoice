# CaloriVoice — основные идеи продукта

1. **Календарь** — по каждому дню видно, сколько калорий пользователь набрал; можно открыть день и посмотреть позиции (что именно съел).

2. **Голос** — основной ввод: пользователь диктует и общается с приложением (добавление еды, уточнения и т.д.).

3. **Иконки блюд** — по надиктованному тексту генерируются простые иконки/картинки того, что пользователь съел (лёгкий визуальный слой дневника).

4. **Быстрый доступ (Apple)** — Shortcuts, виджеты, Action Button, Apple Watch и аналогичные точки входа без полного сценария «открыл приложение».
